# 팀 표준 처치 정의 — 통합본 재실행 명세

통합본 하나로 제출하려면 "전단지 노출"이 세 코드에서 같은 것을 가리켜야 한다.
이 문서는 **표준 정의 + 각자 코드의 정확한 수정 지점 + 재실행 후 연쇄 갱신 목록**이다.
회의에서 확정 후 각자 자기 폴더를 수정·재실행한다.

## 1. 표준 정의 (통일 대상)

| 항목 | 팀 표준 | 근거 |
|---|---|---|
| **전단지 처치** | `mailer IN ('A','C','D','F','H','L')` — 광고 코드만 | J/P는 쿠폰, X/Z는 무료 증정(14만 행). 무료 상품을 처치에 넣으면 수량 효과가 동어반복 |
| **진열 처리** | 전단지 효과 추정 시 진열 동반 셀 **제외** (불가하면 "전단지+진열 패키지 효과"로 명시 재라벨) | 진열 미제외 시 SOFT DRINKS +44.3%→+31.4% (29% 과대) 실측 |
| **정가 공식** | `SALES_VALUE − RETAIL_DISC − COUPON_MATCH_DISC` | User Guide 예시 표 검증. COUPON_DISC는 제조사 보전분이라 빼지 않음 |
| **표본 범위(전단지 분석)** | 매장 115개(causal 커버) · WEEK 9~101 | causal_data "조인 실패 = 무프로모션" 해석이 유효한 범위 |
| **딥할인 기준** | 구매기회 할인율 ≥30% | 이미 3인 동일 — 변경 없음 |

## 2. 통일하지 않는 것 (설계 다양성 — 유지)

- **분석 단위**: 구매기회 조건부(남궁현종·전영찬) vs 0구매 포함 기회 패널(장준한)
  → 내연/외연 마진이라는 서로 다른 질문. 둘 다 필요하다.
- **전영찬 주 처치(실현 딥할인)**: PART B(관측·진단)의 역할. 전단지 표준은
  그의 **보조 분석(07)**에만 적용된다.

## 3. 수정 지점 (파일·줄 단위)

### 남궁현종 — 수정 없음
이미 표준 정의로 구현되어 있다 (`sql/40_mailer_causal/q_causal_clean.sql`). 재실행 불필요.

### 장준한 — 1곳 수정 + phase2부터 재실행

`src/phase2_design/build_mailer_treatment.py` 32행:

```python
# 현재
WHERE c.mailer <> '0'
# 표준
WHERE c.mailer IN ('A','C','D','F','H','L')
```

(선택) 진열 제외까지 반영하려면 같은 쿼리에 display 집계를 추가:

```sql
-- exposure 뷰에 진열 플래그 병행 집계 후, 처치 셀에서 display 동반 제외
SELECT p.COMMODITY_DESC, c.STORE_ID, c.WEEK_NO,
       MAX(CASE WHEN c.mailer IN ('A','C','D','F','H','L') THEN 1 ELSE 0 END) AS ad,
       MAX(CASE WHEN c.display <> '0' THEN 1 ELSE 0 END) AS disp
FROM causal_data c JOIN product p USING (PRODUCT_ID)
GROUP BY 1,2,3
-- 처치 = ad=1 AND disp=0 (또는 disp를 공변량/서브그룹으로)
```

재실행:

```bash
python run_pipeline.py --from phase2 --force
```

체크포인트 구조상 phase2 이후만 다시 돈다. 예상 영향: 헤드라인 효과 크기 **감소, 부호 유지**
(+34.4%가 20%대 후반으로 내려갈 것으로 예상. 남궁현종 데이터 실측 기준 무료증정·진열 혼입은
크기만 부풀리고 방향은 바꾸지 않았다). "56일 payback 없음"은 영향받을 이유 없음.
