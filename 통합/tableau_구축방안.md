# Tableau 대시보드 구축방안

데이터 소스: `통합/outputs/dashboard_*.csv` 9종 (`s5_dashboard_exports.py` 산출, 표준 정의).
각 CSV를 별도 텍스트 파일 연결로 붙인다 — 이미 집계 끝난 소형 테이블이라 조인 불필요.
보고서(`통합보고서.md`)는 여섯 개 질문 순서(효과 있나 → 어디에 통하나 → 경제적으로
가치있나 → 장바구니 전체론 어떤가 → 이후엔 어떻는가 → 그래서 어떻게 배분하나)로 서술하지만,
탭은 밑에 깔린 분석 축(수요·카테고리·고객·세그먼트·하류) 기준으로 5개다 — 질문 하나에 탭
하나가 아니라, 탭 하나가 여러 질문에 걸쳐 쓰인다. 예를 들어 카테고리 포트폴리오 탭은
"어디에 통하나"(net_now)·"경제적 가치"(verdict)·"장바구니 전체"(basket_total)·"배분"(action)
네 질문의 답을 한 화면에서 같이 보여준다.

## 공통 캔버스 사양

- 대시보드 크기: **고정(Fixed) 1366×768** — 5개 탭 전부 동일 크기로 맞춰야 스토리/탭 전환 시
  요소가 튀지 않는다.
- 레이아웃은 전부 **Tiled**(고정 격자)로 짠다. Floating은 범례·필터처럼 다른 요소 위에 얹는
  보조 요소에만 쓴다.
- 상단 제목 바 높이는 5개 탭 공통 60px.

## 공통 색상 규칙

확대=초록 / 축소=빨강 / 불확실=회색 으로 `verdict`·`category_action` 필드에 고정 색상을
지정하고, 이후 모든 탭에서 같은 팔레트를 재사용한다(범례 통일).

## 탭 2 — 카테고리 포트폴리오

**파일**: `dashboard_category_portfolio.csv` (72행)

| 차트 | 타입 | 인코딩 |
|---|---|---|
| 메인 산점도 | Scatter | X=`net_now`, Y=`basket_total`, 색=`verdict`, 테두리 두께=`confidence`(상 굵게), 크기=`n_pairs`, 라벨=`category`(상 등급만 표시) |
| 확증 상위 12개 | 가로 막대 | `confidence`='상' 필터, X=`net_now`, 색=`action`, 정렬 내림차순 |
| 신뢰구간 덤벨 | Dumbbell/막대+오차선 | `net_now_ci_low`~`net_now_ci_high` 범위 + `net_now` 점, 카테고리별 정렬 |

**계산 필드**: `유의표시 = IIF([significant_bh], "●", "")` — 산점도 라벨 옆에 붙여 BH 통과 여부 표시.
**필터**: `confidence`(상/중/하 체크박스), `verdict`.
X=0, Y=0 참조선을 넣으면 산점도가 자연스럽게 4사분면으로 나뉜다(당일 손익 × 장바구니 손익).

**레이아웃**

```
┌────────┬─────────────────────────────────────────────────┐
│ 필터    │  카테고리 포트폴리오                                 │ 60px
│ □상 □중│                                                   │
│ □하    │        메인 산점도 (X=당일 순수취액, Y=장바구니 합계)     │
│        │        색=verdict · 크기=n_pairs · 참조선 X=0,Y=0    │ ~420px
│ 범례    │                                                   │
│ 확대●   ├────────────────────────┬──────────────────────────┤
│ 축소●   │  확증 상위 12개 막대       │  CI 덤벨 (net_now±CI)     │
│ 불확실● │  (confidence='상')       │                          │ ~280px
└────────┴────────────────────────┴──────────────────────────┘
  220px              w/2                       w/2
```

컨테이너 트리: `Dashboard(1366×768)` → `Horizontal` →
`Vertical(좌측 사이드바 w=220, 필터+범례)` /
`Vertical(본문) [Title, 메인 산점도(h=420), Horizontal(h=280)[상위12개 막대, CI덤벨]]`.

## 탭 3 — 고객 타겟팅

**파일**: `dashboard_customer_quintile.csv`, `dashboard_household_axis.csv`

`dashboard_customer_quintile.csv`에 `net_usd`/`ctrl_usd`/`net_usd_ci_low`/`net_usd_ci_high`가
추가돼 있다(3.2절, `s2_allocation.py` [B]). %와 $ 두 관점을 다 보여주도록 구성한다 — %는
"얼마나 늘었나"의 상대 크기를, $는 "실제로 얼마 버는가"의 절대 크기를 말해준다.

| 차트 | 타입 | 인코딩 |
|---|---|---|
| 분위별 효과(%) | 세로 막대 + 오차선 | X=`quintile_kr`, Y=`net_pct`, 오차선=`ci_low`~`ci_high`, 0 기준선(Q1만 마이너스라 색 자동 분리) |
| 분위별 효과($) | 세로 막대 + 오차선 | X=`quintile_kr`, Y=`net_usd`, 오차선=`net_usd_ci_low`~`net_usd_ci_high` — 파라미터로 %차트와 토글 |
| 기준선 지출 비교 | 보조 막대 | X=`quintile_kr`, Y=`ctrl_usd`(전단지 없을 때 평소 지출) — Q1이 Q5보다 높다는 게 바로 보이게, "Q5=큰손"이 아니라 "Q5=할인 있어야 사는 사람"이라는 반전을 뒷받침 |
| 고객 축 검증 | 히트맵 | X=`할인친화도(하류단계)`, Y=`할인의존도(배분단계)`, 색 농도=`households` — 대각선이 진하면 두 정의가 같은 고객을 가리킨다는 근거가 시각적으로 드러남 |

**계산 필드**: 파라미터 `단위선택`(값: "%" / "$") + `분위효과 = IF [단위선택]="%" THEN [net_pct] ELSE [net_usd] END`,
오차선도 같은 방식으로 `ci_low`/`net_usd_ci_low`를 분기.

**레이아웃**

```
┌──────────────────────────────────────────────────────────┐
│  고객 타겟팅                                      [%|$ 토글] │ 60px
├──────────────────────────┬───────────────────────────────┤
│  분위별 효과 (막대+오차선)     │  고객 축 검증 히트맵              │
│  Q5-Q1 격차 $0.479(6.6배)   │  (할인의존도 × 할인친화도)          │ ~460px
│  콜아웃 텍스트               │                               │
├──────────────────────────┼───────────────────────────────┤
│  기준선 지출 비교(Q1>Q5)      │  Spearman ρ=0.800 등 텍스트 캡션  │ ~140px
└──────────────────────────┴───────────────────────────────┘
```

콜아웃 텍스트에는 "구매기회당 순수취액(마진 아님, 원가 데이터 없어 대체 지표) Q1 −$0.063 →
Q5 +$0.415, 격차 $0.479·6.6배" 문구를 그대로 넣는다 — 숫자 옆에 "마진 아님" 캐비엇을 같이
박아둬야 대시보드 보는 사람이 이 값을 원가 차감 이익으로 오해하지 않는다.

컨테이너 트리: `Dashboard(1366×768)` → `Vertical` → `Title` /
`Horizontal(h=600) [분위별 막대(w=50%), 히트맵(w=50%)]` / `Text 캡션(h=60)`.

## 대시보드 간 연동

`category` 필드명이 탭2(`dashboard_category_portfolio`)와 탭5의 카테고리별 사분면
(`dashboard_category_downstream28`)에 공통으로 존재한다. 두 시트가 서로 다른 데이터 소스라도
Tableau 대시보드 액션(필터, 소스 필드=`category`, 대상 필드=`category`)으로 걸면 탭2에서
카테고리 하나를 클릭했을 때 탭5의 해당 카테고리 하류 지표가 하이라이트되도록 연동할 수 있다.

## 빌드 순서

1. `dashboard_*.csv` 9개를 각각 텍스트 파일로 연결 (데이터 원본 9개, 시트는 탭별로 묶기)
2. `verdict`/`category_action`/`quadrant` 등 판정 필드에 공통 색상 팔레트 지정 후 "기본값으로 저장"
   → 이후 만드는 모든 시트에 자동 적용
3. 탭1→5 순서로 위 표대로 시트 제작
4. 탭2·탭5 사이 `category` 필드 대시보드 액션 연결
5. 발표용으로 쓸 경우, 탭 단위가 아니라 **개별 시트 단위**로 스토리(Story)를 짜서 보고서의
   여섯 질문 순서(효과 있나 → 어디에 통하나 → 경제적으로 가치있나 → 장바구니 전체론 어떤가 →
   이후엔 어떻는가 → 배분)를 그대로 재현한다. 탭은 질문 여러 개가 한 화면에 섞여 있지만, 그
   안의 개별 시트(메인 산점도, 분위별 막대, halo 표, 나비넥타이 등)는 각각 질문 하나에
   대응하므로 스토리 포인트로 그 시트만 따로 끌어와 순서대로 배치하면 된다. 탐색용이면 탭
   대시보드만으로 충분하다.
