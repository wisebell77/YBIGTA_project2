**YBIGTA DA 26-2 · Project 2 — Business Insight**
dunnhumby *The Complete Journey* (2,500가구 × 2년 × 259만 거래라인) / BigQuery · Python(DuckDB) · Tableau

세 명이 서로 다른 설계로 독립 분석한 뒤 하나의 의사결정 깔때기로 통합했다.

> **순진한 지표로 재면 결론이 뒤집힌다. 무엇을, 어떻게 세느냐가 전략을 결정한다.**

## 공통 데이터 규약 (틀리기 쉬운 것)

1. **할인 컬럼은 음수다.** 정가 = `SALES_VALUE − RETAIL_DISC − COUPON_MATCH_DISC`
   (`COUPON_DISC`는 제조사 보전분이라 빼지 않는다)
2. **`RETAIL_DISC`는 로열티카드 할인**이지 판촉 할인이 아니다 — 전 라인의 50.2%에 붙어 있다
3. **`QUANTITY`에 계량상품의 그램 값이 섞여 있다** (최댓값 89,638) → winsorize 하거나 금액 지표 사용
4. **`causal_data`는 이벤트 로그다** — `display=0 & mailer=0` 행이 0건. 조인 실패 = "프로모션 없음"이며,
   이 해석은 **매장 115개 · causal 상품 · WEEK 9~101** 범위에서만 유효하다
5. **mailer는 단일 처치가 아니다** — 광고(A,C,D,F,H,L) / 쿠폰(J,P) / 무료 증정(X,Z) 혼재
6. **TypeA 캠페인은 쿠폰 pool 중 16개만 발송**되고 어느 것인지 데이터에 없다 → 쿠폰 단위 분석은 TypeB/C만
