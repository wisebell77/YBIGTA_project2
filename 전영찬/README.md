# 전영찬 — 판촉 이후 고객관계 및 CRM 전략 분석

## 분석 목적
Dunnhumby `The Complete Journey` 데이터를 활용하여 딥할인 구매 이후 고객의 매장 방문과 전체 지출 변화를 측정하고, 카테고리 및 고객 세그먼트별 판촉 전략을 도출한다.

> 본 결과는 할인구매와 정가구매 이후의 관측 성과 차이를 기반으로 하며, 무작위 실험에 의한 인과효과로 단정하지 않는다.

## 핵심 분석 구조
1. 거래·할인 데이터 품질 검증
2. 가구 × 카테고리 × 구매일 기준 구매 occasion 구성
3. 딥할인 구매와 정가구매 비교
4. 할인 후 재구매 및 28/56일 잠식 진단
5. 카테고리별 방문·전체 지출 변화 사분면
6. 사전 RFM, 이탈위험, 카테고리 행동 기반 고객 세그먼트
7. Tableau 카테고리 포트폴리오 및 CRM 전략 대시보드

## 폴더 구성
- `sql/`: BigQuery 분석 쿼리
- `data/`: 집계·비식별 Tableau 입력 데이터
- `tableau/`: Tableau 워크북, 계산필드 및 데이터 생성 파이프라인
- `report/`: 최종 보고서와 분석 초안

## 주요 산출물
- `tableau/대시보드1_카테고리.twb`: 카테고리별 판촉 성과 포트폴리오
- `tableau/대시보드2_고객세그먼트.twb`: 고객 세그먼트별 판촉 성과 및 CRM 전략
- `report/complete_journey_promotion_strategy_report.docx`: 종합 분석 보고서
- `data/tableau_category_kpi.csv`: 카테고리 KPI
- `data/tableau_segment_kpi.csv`: 고객 세그먼트 KPI

## 주요 정의
- 딥할인: 분석 쿼리에 정의된 할인율 기준을 충족한 구매 이벤트
- 정가구매: 할인 영향이 미미한 비교 구매 이벤트
- `visit_diff`: 할인구매 후 관측기간 방문수와 비교 기준의 차이
- `spend_diff`: 할인구매 후 관측기간 전체 매장 지출과 비교 기준의 차이
- `performance_quadrant`: 방문·지출 변화 부호에 따른 4개 성과 유형

## 주의사항
- 저장소에는 원천 거래데이터와 개별 가구 식별자를 포함하지 않는다.
- CSV는 카테고리 또는 세그먼트 수준의 집계 결과이다.
- 원가 데이터가 없으므로 실제 마진이 아니라 지출·수취액 관련 대리지표를 사용한다.
- Tableau 워크북의 데이터 연결은 사용자 환경에 맞게 다시 지정해야 할 수 있다.
